# 👑 프린세스 스토리

메이플스토리풍 횡스크롤 액션 RPG. HTML5 Canvas 단일 페이지 게임으로, **모바일 안드로이드 가로화면에 최적화**되어 있습니다.

## 🎮 플레이

GitHub Pages: https://zeropepsikp.github.io/raelgame/

> 모바일에서 접속하면 화면을 가로로 돌리라는 안내가 표시됩니다. 첫 터치 시 전체화면/가로 고정을 시도합니다.

## 조작법

| 동작 | 모바일 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ 버튼 | ←/→ 또는 A/D |
| 점프 | 점프 버튼 | Space / Alt / W |
| 기본 공격 | 공격 버튼 | Ctrl / Z |
| 프린세스 애로우 (MP 8) | 애로우 버튼 | X |
| 로얄 블래스트 (MP 25, 필살기) | 블래스트 버튼 | C |
| 포탈 이동 / NPC 대화 | 화면 중앙 초록 버튼 | ↑ / Enter |
| 맵 순간이동 | 상단 🗺️ 순간이동 버튼 | - |
| 무기 장착 | 상단 🎒 무기 버튼 | - |
| 구글 로그인 (클라우드 저장) | 상단 G 로그인 버튼 | - |

## 콘텐츠

- **맵 6개**: 프린세스 마을 → 초원 언덕 → 버섯 숲 → 어둠의 동굴 → 자쿰의 제단 / 발록의 둥지
- **일반 몬스터 6종**: 초록달팽이, 슬라임, 주황버섯, 리본돼지, 스켈레톤, 다크골렘
- **보스 2종**: 자쿰(화염구 공격), 발록(추적 + 어둠 구체)
- **NPC 4명**: 상인 로사(HP/MP 회복 상점), 요정 아리엘(가이드), 디자이너 미미(코디샵), 기사단장 가온(보스 안내)
- **맵 순간이동**: 화면 상단 🗺️ 버튼으로 언제든 각 맵 초입으로 이동
- **무기 드랍/장비 시스템**: 몬스터가 7% 확률(보스는 확정)로 무기를 떨어뜨림. 🎒 메뉴에서 장착
- **무기 6종 + 무기별 필살기**:

| 무기 | 스킬1 | 필살기 |
|---|---|---|
| 🗡️ 장검 (기본) | 소드 슬래시 (관통 검기) | 로얄 블래스트 (원형 대폭발) |
| 🪄 마법봉 | 매직 미사일 (별 3발) | 스타폴 (하늘에서 별똥별) |
| 🔪 단검 | 트리플 스탭 (3연격) | 섀도우 러시 (관통 돌진) |
| 🏹 활 | 더블 샷 (화살 2발) | 애로우 레인 (화살비) |
| 🔨 워해머 | 그라운드 슬램 (지면 충격파) | 어스퀘이크 (광역 지진) |
| 🔫 총 | 래피드 샷 (3연사) | 메가 버스터 (거대 레이저) |

- **몬스터 리젠**: 처치 후 8초(보스 30초) 뒤 리스폰, 맵 재진입 시 전체 재생성
- 레벨/경험치/메소 시스템, 몬스터 드롭, 크리티컬, 자동 저장
- **클라우드 저장**: 상단 G 로그인 버튼으로 구글 로그인하면 진행 상황이 Firebase Firestore에 자동 저장(3초 디바운스)되고, 다른 기기에서 이어할 수 있음. 비로그인 시에는 localStorage에만 저장

### Firebase 설정 (콘솔에서 1회 필요)

1. Firebase 콘솔 → Authentication → Sign-in method 에서 **Google 제공업체 활성화**
2. Authentication → Settings → **승인된 도메인**에 `zeropepsikp.github.io` 추가
3. **Firestore Database 생성** 후 보안 규칙 설정:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 캐릭터 커스터마이징

마을의 **디자이너 미미**에게 말을 걸면 코디샵이 열립니다. 다음 부위를 자유롭게 조합할 수 있고, 선택은 자동 저장됩니다. (무기는 코디샵이 아니라 몬스터 드랍 + 🎒 무기 메뉴에서 관리)

| 부위 | 옵션 |
|---|---|
| 헤어 | 금발 긴머리, 핑크 긴머리, 갈색 포니테일, 흑발 단발, 은발 트윈테일, 레드 단발 |
| 모자 | 티아라, 없음, 마법사 모자, 빨간 리본, 밀짚모자 |
| 안경 | 없음, 둥근 안경, 선글라스 |
| 상의 | 핑크/하늘/보라/민트/블랙 드레스 |
| 하의 | 롱 스커트, 미니 스커트, 화이트 롱스커트, 청바지, 블랙 스커트 |
| 신발 | 핑크 구두, 갈색 부츠, 블랙 부츠, 화이트 구두 |

옵션 데이터는 `game.js`의 `EQUIP_OPTIONS`에 정의되어 있어 항목 추가가 쉽습니다.

## 개발

빌드 과정 없음 — 정적 파일(`index.html`, `game.js`)만으로 동작합니다.

```bash
# 로컬 실행
python3 -m http.server 8000
# → http://localhost:8000
```

배포는 `.github/workflows/deploy.yml`이 담당합니다. `claude/maple-story-game-nlkicy` 브랜치에 푸시하면 워크플로우가 `gh-pages` 브랜치로 내용을 동기화하고, GitHub Pages가 `gh-pages` 브랜치를 서빙합니다.
