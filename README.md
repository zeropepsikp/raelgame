# 👑 프린세스 스토리

메이플스토리풍 횡스크롤 액션 RPG. HTML5 Canvas 단일 페이지 게임으로, **모바일 안드로이드 가로화면에 최적화**되어 있습니다.

## 🎮 플레이

GitHub Pages: https://zeropepsikp.github.io/raelgame/

> 모바일에서 접속하면 화면을 가로로 돌리라는 안내가 표시됩니다. 첫 터치 시 전체화면/가로 고정을 시도합니다.

## 조작법

| 동작 | 모바일 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ 버튼 | ←/→ 또는 A/D |
| 점프 | 점프 버튼 | Space / Alt / W |
| 기본 공격 | 공격 버튼 | Ctrl / Z |
| 프린세스 애로우 (MP 8) | 애로우 버튼 | X |
| 로얄 블래스트 (MP 25, 필살기) | 블래스트 버튼 | C |
| 포탈 이동 / NPC 대화 | 화면 중앙 초록 버튼 | ↑ / Enter |

## 콘텐츠

- **맵 6개**: 프린세스 마을 → 초원 언덕 → 버섯 숲 → 어둠의 동굴 → 자쿰의 제단 / 발록의 둥지
- **일반 몬스터 6종**: 초록달팽이, 슬라임, 주황버섯, 리본돼지, 스켈레톤, 다크골렘
- **보스 2종**: 자쿰(화염구 공격), 발록(추적 + 어둠 구체)
- **NPC 3명**: 상인 로사(HP/MP 회복 상점), 요정 아리엘(가이드), 기사단장 가온(보스 안내)
- 레벨/경험치/메소 시스템, 몬스터 드롭, 크리티컬, 자동 저장(localStorage)

## 캐릭터 커스터마이징 (예정)

캐릭터 외형은 `game.js` 상단의 `CHAR_STYLE` 객체(머리색, 드레스색, 피부색 등)로 분리되어 있어, 추후 UI만 붙이면 커스터마이징이 가능합니다.

## 개발

빌드 과정 없음 — 정적 파일(`index.html`, `game.js`)만으로 동작합니다.

```bash
# 로컬 실행
python3 -m http.server 8000
# → http://localhost:8000
```

배포는 `.github/workflows/deploy.yml`이 담당합니다. `claude/maple-story-game-nlkicy` 브랜치에 푸시하면 워크플로우가 `gh-pages` 브랜치로 내용을 동기화하고, GitHub Pages가 `gh-pages` 브랜치를 서빙합니다.
